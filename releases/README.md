# Release records

Each directory holds the metadata of one published release: `manifest.json`, `SHA256SUMS`, `snapshots.csv` and `data_dictionary.csv`. `EDITION` is the current edition. `sources.csv` gives the source zip for each snapshot.

`export` writes a new record here. Commit it before the next monthly run. See [docs/MAINTAINING.md](../docs/MAINTAINING.md).
